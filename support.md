## Frequently asked questions

### How do I create the first account?

The first time you launch the app, the Sign Up screen creates the **Manager** account. Pick a username and a password (at least 4 characters). After that, only the Manager can create more accounts — from **Settings → Users → Add User**.

### What's the difference between Manager, Administrator, and Coach?

- **Manager** — sees everything, can manage other users, can generate every type of report.
- **Administrator** — runs day-to-day: branches, memberships, schedule, inventory, members, attendance. Can generate schedule reports.
- **Coach** — sees only their schedule and settings.
- **Other** — a custom role; the Manager picks exactly which tabs the user can see.

A Manager can override any user's tab access individually from Settings → Users → tap the user.

### I forgot the Manager password. Can I reset it?

There's no remote password reset because the app is local-first — your data never leaves your device. If no Manager exists in the database (e.g. the only Manager was deleted), the Sign Up screen reappears so you can create a new one. If a Manager still exists but you've forgotten the password, the only way to recover is to delete the app and start fresh — note that this also wipes all academy data, so back it up first using the **Generate Report** functions.

### How do I back up my data?

Generate the reports you need from **Settings → Reports** (Manager) — they save as PDFs you can email to yourself or save to Files / iCloud Drive. iOS itself also includes the app's data in iPhone backups (iCloud Backup or Finder/iTunes backup).

### Why don't I see all members on the Attendance tab?

Members only appear in Attendance on the days their **membership operates**. If a Red Beginner Morning runs Sunday + Tuesday, those members appear in Attendance only on Sunday and Tuesday. Pick a different date in the date picker to see other groups.

### How are coach hours calculated?

Hours come from sessions you mark **Confirmed** on the General Schedule day view. Until a day is confirmed, its hours don't count toward payroll or coach totals. You can also unlock a confirmed day to remove its hours.

### How are membership end dates calculated?

The end date is computed from the membership's start date, the number of total sessions, the membership's operating days, and the member's absences. Each absence pushes the end date forward by one more scheduled day.

### Can multiple people share one academy?

Yes — within the same iPhone or iPad. Create separate user accounts for each role. All accounts share the same data; the role just controls what each person sees. The app does not currently sync across devices.

### How are reports formatted?

PDF reports include the Academy Manager logo as a watermark and a footer with your academy name (set in Settings → Academy). They open in any PDF viewer and can be emailed, AirDropped, printed, or saved to Files.
